1.程序简介
本程序为三维空间桁架杆单元有限元计算程序，基于Python+NumPy实现。可完成三维杆单元刚度矩阵求解、节点位移下的应变/应力/轴力计算，
并对刚度矩阵力学数学性质进行完整性验证，适用于有限元单元原理学习与算例验证。
2.程序说明
单元自由度顺序（固定）：1x、1y、1z（节点1三向平动）、2x、2y、2z（节点2三向平动）。
输出为零
3.运行环境
Python 3.12.4（3.7以上均可使用）
依赖库：numpy
编写工具：jupyter notebook
4.运行方式
正常运行python脚本即可，无需额外配置环境，但必须由numpy库。
运行后自动输出：单元几何参数、方向余弦、刚度矩阵、力学结果、两算例的结果。
5.输出内容说明
单元长度、方向余弦
6×6单元刚度矩阵
轴向应变、轴向应力（MPa）、杆件轴力
矩阵对称性、奇异性、特征值、刚体位移验证结果
刚度矩阵物理意义校验结果
